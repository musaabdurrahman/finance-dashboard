# Personal Finance Dashboard

An interactive Streamlit dashboard for exploring income, spending and balance trends.

## Features
- 6 KPIs: transactions, total income, total expenses, net balance, average expense, savings rate
- Date-range and category filters
- Charts: spending by category, income by category, balance over time

## Data
Uses 12 months of synthetic transaction data generated by `generate_data.py`
(fixed random seed, so it's reproducible). The generator models realistic
behaviour: right-skewed spending amounts, seasonal patterns, a mid-year pay rise
and one-off purchases.

## Run it
pip install streamlit pandas altair numpy
python generate_data.py
streamlit run app.py
